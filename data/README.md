## ความหมายที่ควรรู้

- **เกรดขั้นต่ำ (`min_gpax`):** เกรดเฉลี่ย 5 เทอม ค่า 0 = ไม่กำหนด
- **สัดส่วนคะแนน:** รวมกัน 100% ในหลักสูตรส่วนใหญ่ (2,658 จาก 2,755 หลักสูตรที่ระบุสัดส่วน) ที่ไม่ครบ 100% คือหลักสูตรที่มี "กติกาพิเศษ" เช่น เลือกวิชาที่ได้ดีที่สุดบางวิชา (ดูใน `note` หรือ `special_calc`) เว็บจะไม่คำนวณโอกาสติดให้หลักสูตรเหล่านี้
- **วิชาสัดส่วน 0%:** หลักสูตรระบุ "คะแนนขั้นต่ำ" ของวิชาแต่ไม่ระบุน้ำหนัก (960 แถว) เก็บไว้เพื่อให้รู้ว่าต้องสอบวิชานั้น
- **คะแนนปีก่อน:** คะแนนรวมต่ำสุด/สูงสุดของผู้ที่ได้รับคัดเลือกรอบ 3 ใช้ค่าหลังประมวลผลรอบสุดท้าย (`min_score_final`) เทียบข้ามปีได้ตั้งแต่ปี 2567 (เริ่มใช้ TGAT/TPAT/A-Level) ไฟล์ปี 2565–2566 เป็นระบบ GAT/PAT เทียบไม่ได้ จึงไม่รวม
- **หัวข้อที่ต้องอ่าน:** มาจากหน้า "โครงสร้างข้อสอบและตัวอย่างข้อสอบ" ของ TCAS70 ทุกวิชา (A-Level 16 วิชา, TGAT1-3, TPAT2-5) ส่วน TPAT1 (กสพท) ไม่มีหน้าโครงสร้าง ใช้ 3 องค์ประกอบจากตารางรหัสวิชาของ TCAS (เชาว์ปัญญา, จริยธรรมทางการแพทย์, การเชื่อมโยง) รหัส `tgat` (รวม) = หัวข้อของ TGAT1+2+3

## ข้อจำกัด (ควรรู้ก่อนใช้จริง)

1. **เกณฑ์ปี 2570 ยังอาจเปลี่ยน** มหาวิทยาลัยบางแห่งแก้ไขหลังประกาศ ควรรันสคริปต์ดึงข้อมูลใหม่ก่อนช่วงเปิดรับสมัครจริง
2. **รอบ 2 (โควตา) ส่วนใหญ่เป็นข้อความเงื่อนไข** TCAS เก็บเกณฑ์โควตาเป็นข้อความตามโครงการ (มีเพียง 86 รายการที่ระบุสัดส่วนแบบโครงสร้าง และเป็นเกรด/แฟ้มสะสมผลงาน/สัมภาษณ์ ไม่มี TGAT หรือ A-Level) จึงมีเฉพาะเกรดขั้นต่ำที่เป็นตัวเลข (1,752 จาก 5,193 รายการ) ส่วนที่เหลืออยู่ในช่อง `note`/`condition` ไม่ได้แปลงเป็นตัวเลข และรอบ 2 **ไม่มีคะแนนปีก่อน** เพราะ TCAS ไม่เผยแพร่ในรูปแบบเดียวกับรอบ 3
3. **คะแนนปีก่อนมี 2,880 จาก 3,255 รายการรอบ 3** อีก 375 รายการเป็นหลักสูตรใหม่ หรือไม่เคยเปิดรับในระบบ TCAS67–69 หรือรหัสหลักสูตรเปลี่ยน
4. **ไม่ได้เก็บข้อมูลจากเว็บไซต์ของแต่ละมหาวิทยาลัย** ใช้เฉพาะข้อมูลที่ TCAS รวบรวมไว้ (เว็บมหาวิทยาลัยแต่ละแห่งต่างรูปแบบกันมาก และเป็นข้อความอิสระ ตรวจความถูกต้องไม่ได้ในวงกว้าง) หลักสูตรที่ต้องการรายละเอียดเพิ่ม ให้เปิดลิงก์ในช่อง `link` ของหลักสูตรนั้น
5. **หัวข้อที่ต้องอ่านเป็นระดับ "โครงสร้างข้อสอบ"** (เช่น ฟิสิกส์ 19 หัวข้อ คณิต 1 มี 16 หัวข้อ) ซึ่งเป็นขอบเขตอย่างเป็นทางการ ยังไม่ได้แตกเป็นหัวข้อย่อยรายบทเรียน ม.4–ม.6 เพิ่มเองได้ในตาราง `topics`
6. **คะแนนปีก่อนเป็นระดับหลักสูตร (ผลรวมถ่วงน้ำหนัก)** ไม่มีรายวิชา จึงบอกได้ว่า "คะแนนรวมควรได้เท่าไร" แต่บอกรายวิชาไม่ได้

## วิธีนำข้อมูลเข้าเว็บ (ทำครั้งเดียว)

> เตรียม: เปิด Supabase → โปรเจกต์ `dekpro`  ทุกไฟล์ SQL อยู่ในโฟลเดอร์ `supabase/`

**ขั้นที่ 1: เพิ่มคอลัมน์ใหม่**
SQL Editor → ลบช่องให้ว่าง → วางทั้งไฟล์ `supabase/migration-real-data.sql` → **Run** (ต้องขึ้น `Success`)
ขั้นนี้เพิ่มคอลัมน์ในตาราง `programs` (รหัสหลักสูตร TCAS, ชื่อโครงการ, ลิงก์, คะแนนปีก่อน) และสร้างตาราง `program_score_history`

**ขั้นที่ 2: ล้างข้อมูลตัวอย่างเดิม**
SQL Editor → ลบช่อง → วาง `supabase/clear-sample-data.sql` → **Run** ผลต้องได้ `0, 0, 0`
(ผลกระทบ: เช็คลิสต์ที่เคยสร้างจากข้อมูลตัวอย่างหายไป และผู้ใช้ต้องเลือกคณะใหม่ ข้อมูลอื่นไม่เสีย)

**ขั้นที่ 3: นำเข้า CSV ตามลำดับนี้** (ลำดับสำคัญ เพราะตารางอ้างอิงกัน)

| ลำดับ | ไฟล์ | ตาราง |
|---|---|---|
| 1 | `data/tcas70/app_topics.csv` | `topics` |
| 2 | `data/tcas70/app_programs_round3.csv` | `programs` |
| 3 | `data/tcas70/app_programs_round2.csv` | `programs` |
| 4 | `data/tcas70/app_program_subjects.csv` | `program_subjects` |
| 5 | `data/tcas70/app_score_history.csv` | `program_score_history` |

ทำแต่ละไฟล์: Supabase → **Table Editor** → เลือกตาราง → ปุ่ม **Insert** → **Import data from CSV** → ลากไฟล์เข้าไป →
ตรวจว่าชื่อคอลัมน์จับคู่กันครบ (ขึ้นชื่อตรงกันทั้งหมด ไม่มีคอลัมน์สีแดง) → **Import data**
ไฟล์ใหญ่อาจใช้เวลา 1–2 นาที อย่าปิดหน้าต่าง

**ขั้นที่ 4: ตรวจว่าครบ**
SQL Editor → วาง `supabase/verify-real-data.sql` → Run ต้องได้ `programs_r3 = 3255`, `programs_r2 = 5193`, `subjects = 8189`, `topics = 257`, `history = 7931`

**ขั้นที่ 5: ลองบนเว็บ**
เปิดเว็บ → โปรไฟล์ → แก้ไข → เลือกรอบ 3 → จุฬาลงกรณ์มหาวิทยาลัย → คณะวิศวกรรมศาสตร์ → จะเห็นสาขาจริง แล้วไปหน้า **เกณฑ์** (ต้องเห็น TGAT 20%, TPAT3 30%, A-Level คณิต 1 20%, ฟิสิกส์ 20%, เคมี 10% และตารางคะแนนปี 2567–2569) และหน้า **เช็คลิสต์** (หัวข้อจริง 75 หัวข้อ)

### ถ้านำเข้าแล้วขึ้น error
| อาการ | วิธีแก้ |
|---|---|
| `column "tcas_program_id" does not exist` | ยังไม่ได้ทำขั้นที่ 1 ให้ทำก่อน |
| `foreign key ... program_subjects` | นำเข้าผิดลำดับ ลบข้อมูลในตาราง `program_subjects` แล้วนำเข้า `programs` ให้ครบก่อน |
| `duplicate key value violates unique constraint "programs_pkey"` | นำเข้าไฟล์ `programs` ซ้ำ ให้รัน `clear-sample-data.sql` แล้วเริ่มขั้นที่ 3 ใหม่ |
| ภาษาไทยเป็นตัวต่างดาว | ไม่ได้เลือก UTF-8 ในโปรแกรมที่ใช้เปิดไฟล์ (Supabase เองอ่านไฟล์เหล่านี้ได้ถูกต้อง) |
| ไฟล์ใหญ่เกินที่ Table Editor รับ | แจ้งฉัน จะแบ่งไฟล์ให้เล็กลง หรือสร้างเป็นไฟล์ SQL ให้นำเข้าแทน |

## อัปเดตข้อมูลให้เป็นปัจจุบัน

เมื่อ TCAS ประกาศเกณฑ์เพิ่ม ให้รันคำสั่งนี้ แล้วทำขั้นที่ 2–4 ใหม่ (ไม่ต้องทำขั้นที่ 1 อีก)

```bash
python3 scripts/build_tcas_dataset.py --refresh
```

คำสั่งนี้ใช้ Python มาตรฐาน ไม่ต้องติดตั้งอะไรเพิ่ม ดาวน์โหลดข้อมูลสาธารณะใหม่ทั้งหมด (ใช้เวลาประมาณ 1 นาที) และเขียนทับไฟล์ใน `data/tcas70/`
ไฟล์ดิบที่ดาวน์โหลดเก็บใน `data/raw/` (ไม่ขึ้น GitHub)
